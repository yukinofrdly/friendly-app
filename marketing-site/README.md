# FRIENDLY HP — WordPress 統合パッケージ

FRIENDLY 公式サイト (HTML/CSS/JS で作られた LP) を、**WordPress の固定ページとして動かす**ためのパッケージです。

---

## 構成

```
wordpress/
├── README.md              ← 本ファイル (まず読む)
├── MAINTENANCE.md         ← 運用・修正のやり方
├── page-content.html      ← 固定ページに貼り付ける HTML
└── mu-plugins/
    ├── friendly-hp.php            ← 統合プラグイン (アセット読込・フォーム送信)
    └── friendly-hp-assets/        ← CSS / JS / 画像 (全てここに集約)
        ├── styles.css
        ├── script.js
        ├── js/
        │   ├── animations.js
        │   ├── contact.js
        │   └── debounced.js
        └── images/
```

### なぜこの構成か (設計意図)

| レイヤー | 役割 | 編集頻度 | 編集する人 |
|---|---|---|---|
| **固定ページ本文** (`page-content.html`) | テキスト・構造 | 高 | コンテンツ担当 |
| **mu-plugin** (`friendly-hp.php`) | アセット読込・フォーム宛先・スパム対策 | 低 (設定変更時のみ) | 開発担当 |
| **アセット** (`friendly-hp-assets/`) | デザイン・アニメーション・画像 | 中 | デザイン担当 |

→ **役割が分離**しているので、文言修正で CSS が壊れたり、画像差し替えで PHP が壊れたりしません。

## セットアップ手順 (初回のみ)

### 1. ファイルをサーバへ配置

WordPress のインストール先 (`wp-content/`) に対して、以下のようにアップロードします。

```
wp-content/
├── mu-plugins/                     ← 無い場合は新規作成
│   ├── friendly-hp.php             ← 本パッケージから配置
│   └── friendly-hp-assets/         ← 本パッケージから配置 (フォルダごと)
└── themes/
    └── (お使いのテーマ)/             ← テーマは触りません
```

> **ポイント**: `mu-plugins` (Must-Use Plugins) は WordPress が**自動で有効化**する特別なフォルダです。  
> プラグイン管理画面での有効化操作は不要、テーマを変更しても効き続けます。

FTP / SFTP / cPanel ファイルマネージャ / SSH のいずれかで配置してください。

### 2. 固定ページを作成

1. WordPress 管理画面 → **固定ページ** → **新規追加**
2. **タイトル**: `FRIENDLY` (任意)
3. **URL スラッグ**: `home` ← **mu-plugin のデフォルト設定と一致**させる
   - スラッグを変えたい場合は、`mu-plugins/friendly-hp.php` 冒頭の `FRIENDLY_HP_PAGE_SLUG` も書き換える
4. **本文の入力**:
   - **ブロックエディタ (Gutenberg) の場合**:
     1. 右上の「︙」→ **コードエディター** に切替え
     2. `page-content.html` の中身を全文コピーして貼り付け
     3. **ビジュアルエディター**に戻す (戻さなくても保存可)
   - **クラシックエディタの場合**: 「テキスト」タブに `page-content.html` の中身を貼り付け
5. **テンプレート**: 可能なら「**フルワイド**」「**コンテンツのみ**」「**Blank**」など、テーマのヘッダー/サイドバー/フッターを使わないテンプレートを選択 (テーマによって名称が異なる)
6. **公開**

### 3. トップページに設定する場合 (任意)

このページをサイトのトップにする場合:

1. **設定** → **表示設定**
2. **ホームページの表示** → **固定ページ** を選択
3. **ホームページ** に手順 2 で作った固定ページを指定

→ `mu-plugin` は `'home'` スラッグ かつ フロントページの場合も自動で対象判定するので、追加設定は不要です。

### 4. 動作確認

固定ページの URL にアクセスして、以下を確認してください。

- [ ] ナビゲーション・全セクションが表示される
- [ ] 画像が表示される (壊れた画像がない)
- [ ] ヒーローのアニメーション (タイトルが入ってくる) が動く
- [ ] スクロールで FEATURE、CASE STUDIES などのアニメーションが発火
- [ ] FAQ の Q をクリックするとアコーディオンが開く
- [ ] お問い合わせフォームから送信できる (テスト送信を推奨)
- [ ] モバイル幅 (375px / 768px) でも崩れない
- [ ] ハンバーガーメニューが動く

問題があった場合は **MAINTENANCE.md → トラブルシューティング** を参照してください。

## お問い合わせフォームについて

### 採用した方式 — 既存 HTML フォーム + WordPress 標準メール送信

```
ユーザー入力
   ↓
admin-post.php (WordPress 標準エンドポイント)
   ↓
mu-plugin が受け取り
   ↓
nonce 検証 → honeypot → 必須チェック
   ↓
wp_mail() で送信先・自動返信メールを送信
   ↓
?contact=success or error でリダイレクト
   ↓
JS が成功/失敗バナーを表示
```

**メリット**
- 既存デザイン (フォームの見た目) を一切変更しない
- 追加プラグイン不要
- nonce + honeypot で最低限のスパム対策あり
- 自動返信メール対応済み

**現在の設定**
| 項目 | 値 | 変更場所 |
|---|---|---|
| 送信先 | `info@friendly.co.jp` | `mu-plugins/friendly-hp.php` の `FRIENDLY_HP_MAIL_TO` |
| 件名 | `【FRIENDLY HP】お問い合わせを受信しました` | 同上 `FRIENDLY_HP_MAIL_SUBJECT` |
| 自動返信 | あり (送信者宛) | mu-plugin 内の `wp_mail()` 部分 |

### 他の選択肢 (参考)

| プラグイン | 特徴 | 切替えやすさ |
|---|---|---|
| **Contact Form 7** | 日本で最も普及・無料・実績多数 | フォーム部分のみ差替え。MAINTENANCE.md に手順記載 |
| **WPForms** | UI がモダン・条件分岐可・有料版あり | 同上 |
| **Snow Monkey Forms** | 日本製・確認画面標準・無料 | 同上 |
| **Formspree / Getform 等 SaaS** | サーバ側コード不要・無料枠あり | `<form action="...">` を 1 箇所差替えるだけ |

切替手順は `MAINTENANCE.md → フォームを別プラグインに変更する` を参照。

## よくある質問

### Q. テーマのヘッダー・フッターと二重に見えてしまう

A. テーマのヘッダー/フッターを使わない「全幅 / コンテンツのみ」テンプレートを選択してください。お使いのテーマに該当テンプレートがない場合、簡単な「空白ページテンプレート」を作成する方法を MAINTENANCE.md に記載しています。

### Q. 画像が表示されない

A. `mu-plugins/friendly-hp-assets/images/` がサーバ上の同じパスに正しくアップロードされているか確認してください。ブラウザの開発者ツール (F12) の「Network」タブで 404 になっている画像のパスを見ると、どこを修正すべきかわかります。

### Q. アニメーションが動かない

A. ブラウザの開発者ツールのコンソールで JS エラーが出ていないか確認してください。CDN (cdn.jsdelivr.net) からの GSAP 読み込みに失敗しているケースが多いです。社内ネットワークが CDN をブロックしている場合は、GSAP を mu-plugin フォルダにダウンロードしてローカル参照に変更できます (MAINTENANCE.md 参照)。

### Q. メールが届かない

A. WordPress 標準の `wp_mail()` はサーバの PHP `mail()` 関数に依存するため、サーバ設定によっては届かないことがあります。**WP Mail SMTP** などのプラグインを入れて SMTP 経由で送るのを推奨します (Gmail / SendGrid / さくらメールボックスなど)。

- WordPress 6.0+
- PHP 8.0+
- インターネット接続 (Google Fonts と GSAP を CDN から読み込むため)
